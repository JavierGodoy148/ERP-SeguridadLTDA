# HU-02: Modelo de cálculo paramétrico de remuneraciones

## Historia de Usuario
Como jefe de RRHH, quiero configurar haberes, descuentos y parámetros 
con sus fórmulas para que el sistema calcule automáticamente las 
liquidaciones de sueldo del personal.

## Criterios de Aceptación
- Se crean haberes, descuentos y parámetros personalizados
- Las fórmulas relacionan correctamente los conceptos
- El resultado de la liquidación es consistente
