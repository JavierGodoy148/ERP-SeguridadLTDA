# HU-22: Ficha del cliente

## Historia de Usuario
Como vendedor, quiero gestionar la ficha del cliente con datos básicos, 
direcciones de despacho, plazo de pago y lista de precio asociada.

## Criterios de Aceptación
- Se ingresan datos básicos del cliente
- Se agregan múltiples direcciones de despacho
- Se asocia lista de precio y plazo de pago
