# HU-21: Gestión de listas de precios y promociones

## Historia de Usuario
Como administrador, quiero gestionar listas de precios con márgenes, 
descuentos, ofertas y promociones con fechas de vigencia, actualizables 
de forma masiva.

## Criterios de Aceptación
- Se crean listas con márgenes o descuentos sobre precio base
- Las ofertas tienen fecha de inicio y término
- La actualización masiva funciona correctamente
