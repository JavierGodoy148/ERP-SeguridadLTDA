# HU-16: Emisión de etiquetas de productos

## Historia de Usuario
Como bodeguero, quiero generar etiquetas para productos seleccionados 
en distintos formatos de impresión, para facilitar la identificación 
física del inventario.

## Criterios de Aceptación
- Se seleccionan productos y se generan etiquetas
- Se soportan distintos formatos de impresión
- Las etiquetas incluyen las características del producto
