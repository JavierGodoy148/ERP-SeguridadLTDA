# HU-15: Ficha completa de productos

## Historia de Usuario
Como bodeguero, quiero registrar productos con código alfanumérico 
(hasta 20 caracteres), grupo, subgrupo, código de barra, fotografía, 
ficha técnica y atributos especiales (serie, talla, vencimiento, kit).

## Criterios de Aceptación
- Código alfanumérico hasta 20 caracteres
- Se adjuntan fotografía y ficha técnica
- Se registran atributos especiales (serie, talla, kit, vencimiento)
- Botones de consulta directa de stock, ventas y compras
