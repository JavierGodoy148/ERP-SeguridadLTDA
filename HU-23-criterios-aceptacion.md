# HU-23: Catálogo de productos multimedia

## Historia de Usuario
Como cliente, quiero explorar el catálogo de productos con texto, video, 
múltiples imágenes, archivos descargables y pestañas descriptivas.

## Criterios de Aceptación
- Se muestran productos con todos los atributos multimedia
- Se organizan por categorías y marcas
- Hay pestañas descriptivas navegables
